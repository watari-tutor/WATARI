# 🚀 WATARI — Future Roadmap

> **The journey doesn't stop here.** WATARI is continuously evolving to make studying smarter, more organised, and more engaging. Here's a look at what's already been built and what's coming next! 💜

This roadmap is based on feature ideas shared on **8 October 2026**. Development is planned in stages — starting with reliability and core study workflows, then expanding into AI, social learning, and gamification.

---

## 0. 🔔 Fix Daily Prompt Flow
**Status: ✅ COMPLETED**

- [x] Show the sleep log prompt first whenever it is due. 😴
- [x] After sleep is saved, show the attendance prompt if an institution's departure time has passed and attendance is still missing. 🏫
- [x] Keep attendance status and departure time independent for each selected institution, allowing students to track school, college, and coaching separately. 📚

## 1. 🗺️ Make Core Study Planning Clearer
**Status: ✅ COMPLETED**

- [x] Simplify navigation and screen layouts for a cleaner experience. ✨
- [x] Add an exam calendar to Exam Control, allowing students to add and edit exam dates. 📅
- [x] Make **Roadmap** the complete syllabus, organised in prerequisite order — from the first topic to the last. 🗺️
- [x] Make **Backlog** a dedicated space for weak topics, organised by High, Medium, and Low priority. 🎯
- [x] Allow students to add backlog topics manually, directly from Roadmap, or with AI.
- [x] For Roadmap topics, let students specify their weak areas: practice questions, concepts, full chapter, specific subtopics, or numericals. 🧠
- [x] Add revision reminders to the To-do List until a weak area is marked as mastered. 🔁

## 2. 🧩 Turn Quizzes into a Learning Loop
**Status: ✅ COMPLETED**

- [x] Turn generated Quiz Lab questions into interactive quizzes with multiple-choice and integer-answer questions. 📝
- [x] When an answer is incorrect, identify the tested topic and question pattern, then offer to add it to Backlog and Mistake Bank and create a revision task. ⚡
- [x] When a backlog topic is completed, generate a mastery quiz based on its weak areas and related mistakes. Add it to the command queue and To-do List. 🏆

**The goal:** Don't just tell students what they got wrong — help them work on it.

## 3. 🤖 Add Richer AI Study Materials
**Status: ✅ COMPLETED**

- [x] Allow image and document attachments in AI questions across Talkable Chat, Doubt Solver, and Study AI generators. 📎
- [x] Generate handwritten-style short-note images with interactive zoom controls and PNG export. 🗒️
- [x] Include direct links to YouTube deep-dives and academic sources for further learning. 🔎
- [x] Upgrade Flowchart into an interactive concept map inspired by notebook-based AI research tools. 🧠
- [x] Add category filters, formula callouts, and trap warnings.
- [x] Add one-click actions: **Ask Tutor**, **Quiz Node**, and **Add to Backlog**. 🚀

## 4. 🧠 Personalize the Tutor and AI Agent
**Status: 🔜 PLANNED**

- [ ] Adapt explanations and practice questions to students' demonstrated learning needs using saved study history — with clear student control over that history. 🎯
- [ ] Introduce a conversational AI agent that can gather requested information and navigate to relevant areas of WATARI. 🤖
- [ ] Ask for confirmation before the agent takes consequential actions outside the app. 🔐

**The vision:** A tutor that understands how you study and an agent that helps you get things done.

## 5. 🌳 Build Motivation and Social Study
**Status: 🚧 PARTIALLY COMPLETED**

### 🏆 Achievements & Gamification

- [x] Add a profile featuring level, achievements, and rank. 👤
- [x] Award **5 XP** for every 5 minutes of focus. ⏱️
- [x] Award **3 XP** for every correct quiz answer. ✅
- [x] Reward backlog completion:
  - 🔴 High Priority — 50 XP
  - 🟡 Medium Priority — 35 XP
  - 🟢 Low Priority — 20 XP
- [x] Define five achievement tiers: Bronze, Silver, Gold, Platinum, and Diamond. 💎
- [x] Introduce selectable AI avatars with tier-based badge aura effects. ✨

### 🌲 Forest Island & Social Learning

- [ ] Make Forest Island interactive — zoom, pan, and place or move trees. 🌱
- [ ] Let friends start study challenges together. 🤝
- [ ] Add progress comparisons and shared challenge streaks. 🔥

## 6. ☁️ Sync and Smart Reminders
**Status: 🔜 PLANNED**

- [ ] Complete cross-device synchronisation with conflict handling and clear sync status. ☁️
- [ ] Introduce notifications for focus sessions, quizzes, and revision reminders. 🔔
- [ ] Add notification settings so students can choose which alerts they want to receive. ⚙️

---

## 🛣️ Suggested Development Order

Here's the planned journey for WATARI's development:

1. ✅ **Daily Prompt Flow** — Sleep logging and independent attendance records.
2. ✅ **Study Planning** — Exam calendar, Roadmap, Backlog, and priorities.
3. ✅ **Quiz Learning Loop** — Interactive quizzes, Mistake Bank, and revision workflow.
4. ✅ **AI Study Materials** — Attachments, handwritten notes, and interactive concept maps.
5. 🔜 **The Next Chapter** — Sync, notifications, AI agent, personalised learning, and social features.

*The order of upcoming releases may change as development progresses and feedback comes in.*
